# CSS Basics

A structured collection of CSS practice, exercises, and mini projects created while learning front-end web development.

## About This Repository

This repository follows a hands-on CSS learning path, starting with core styling concepts and progressing to layouts, positioning, overflow, reusable page styling, and animations.

## Learning Path

- **Day01-Day05:** CSS fundamentals, selectors, colors, typography, box model, and basic styling
- **Day06:** CSS positioning and layout practice
- **Day07:** Float, overflow, z-index, and layout projects
- **Day08-Day09:** Page recreation and responsive styling practice
- **Day10-Day16:** Additional CSS exercises and project-based practice
- **Day17:** CSS animations

## Topics Covered

- CSS syntax and selectors
- Colors, fonts, and text styling
- Box model, borders, padding, and margins
- Display and positioning
- Float and overflow
- Z-index and stacking order
- Backgrounds and visual styling
- Page layouts and component styling
- CSS animations
- Building pages with HTML and CSS

## Projects and Practice

The repository includes small exercises and mini projects such as:

- Flag designs using HTML and CSS
- Zomato-inspired page layouts
- Layout practice using positioning and float
- Styling exercises for common web page elements
- Animation experiments

## How to View the Files

1. Clone the repository:

   ```bash
   git clone https://github.com/prbharti25/CSS-basics.git
   ```

2. Open the cloned folder in VS Code.
3. Open any HTML file in a browser, or use the Live Server extension for a better development workflow.
